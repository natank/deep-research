# Deep Research

A portfolio demo app: enter a research topic, get a synthesized report (summary, sources, and a data visualization), generated by an LLM-driven pipeline (planner → searcher → writer → emailer).

See [`docs/purpose.md`](docs/purpose.md) for the project brief and [`docs/master-plan.md`](docs/master-plan.md) for the phased implementation plan.

## Project layout

- `backend/` — FastAPI service (Python, managed with [uv](https://docs.astral.sh/uv/)) implementing the planner/searcher/writer/emailer pipeline.
- `frontend/` — React + TypeScript web UI (Vite).

## Setup

1. Copy `.env.example` to `.env` at the repo root and fill in `OPENAI_API_KEY`.
2. Backend:
   ```sh
   cd backend
   uv sync
   uv run fastapi dev app/main.py
   ```
3. Frontend:
   ```sh
   cd frontend
   npm install
   npm run dev
   ```

## Testing

```sh
cd backend
uv run pytest
uv run ruff check .
```
